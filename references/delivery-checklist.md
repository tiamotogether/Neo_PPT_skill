# 交付检查表

按本次交付范围使用。已有验证结果可以复用，但发生修改后要检查受影响内容及对应导出文件；不把旧版本的通过记录当作新版本证明。

## 内容与来源

- 用户要求的章节、关键论点、指定材料、指定来源页段及指定案例已经覆盖。
- 删除项在用户指定范围内消失。删除整页或主题时，同步大纲、目录、讲稿及缩略图；只删来源行时，不扩大为删除讲稿中的引用。
- 人名、机构、历史时间、数据单位、统计范围和成果状态与来源一致。
- 计划/测试/试用/阶段验收/实际经营结果的表述不混淆；图注不冒认照片、界面或AI作品。
- 演讲节奏标签未混入观众页面；历史日期、真实业务耗时与工作周期没有被误删。
- 每页讲稿与该页内容对应，不用相同套话填满所有备注。

## 逐页画面

实际渲染全部页面或在原应用逐页查看；不能只检查封面和几张代表页。

- 比例正确，页码连续，总页数和目录一致。
- 字体加载正常，中文无缺字，图片不丢失、不拉伸，二维码和重要标识不变形。
- 标题、正文、表格、图注、结论、出处和页脚无遮挡、越界或被截断。
- 蓝底/白底层级稳定，章节与案例顺序清楚；重点可在投影画面直接辨认。
- 带文字的真实图表逐一看清，不把模糊原图当作可读信息。

若有自动检查，结合实际画面审查；有意的局部图裁切与允许为空的来源区域不能被机械误判。

## 演示操作

- 试用前后翻页、Home/End、页码输入、章节跳转、缩略图选页和全屏。
- 首页和末页操作正常，页码范围覆盖完整页数；输入异常页码能合理处理。
- 打开/关闭讲稿、图片放大/关闭；弹窗或总览打开时，按键不要同时翻动背后的页面。
- 演讲者窗口的当前页、下一页、讲稿与主屏同步，末页不越界。
- 在较小窗口下确认画面仍等比缩放，基本导航可操作。
- 将独立HTML复制到不含原素材的临时目录，断网打开，确认图片、字体和演示功能仍能使用。

## 导出和打包

- PDF页数、顺序、比例和关键页面与HTML一致；工具栏、讲稿、弹窗未混入PDF。
- 实际打开或渲染导出的PDF，而非只检查文件存在。
- 若提供PPTX，实际打开检查版式、图片和讲稿。整页图片式PPTX应明确说明编辑限制，不能称其文字可编辑。
- 页面图片数量与总页数一致；文件名能按页码正确排序。
- 二维码从最终画面实际识别，与用户提供的原二维码核对。
- 压缩包重新打开检查，包含的HTML、PDF、讲稿及图片是最新版本。不要把旧成品或调试文件混作交付文件。
- 文件入口清楚，旧版本可恢复。若已有发布或上传任务，另外验证目标端打开的是新版本；本地成品不等于已完成远端交付。

## 限定修改的额外检查

保存修改前版本。先定位用户所指页面及元素，再修改；对照前后内容和画面，只允许本次指定差异。

例如“删除所有带某PPT引用的来源说明整行”：

1. 在所有页面搜索大小写、空格等可能的写法，并检查图注及页底区域。
2. 删除命中的完整来源行；未命中的来源、正文和逐页讲稿不动。
3. 若本次同时维护制作源文件，更新相应生成入口，避免下次导出时原来源行重新出现；只要求另存演示版时，不擅自修改其他制作文件。
4. 搜索确认观众页面没有遗漏；对照其余内容一致。
5. 只同步本次交付范围内已有的对应文件（如HTML、PDF、页面图片或交付包），再打开检查；不因一次小改新增无关交付物。

汇报只说明改动范围、是否检查通过和可用入口。未完成的必要检查要如实说明原因。
