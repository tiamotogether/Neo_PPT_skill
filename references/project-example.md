# 来源项目示例：清华大学三小时演讲

本技能总结自已完成的清华演讲制作与逐页整改。以下记录仅帮助理解方法，不是所有新PPT必须复制的内容、人物、数据或页数。

## 从材料到讲述主线

- 材料包括学员信息、已有讲稿、AI与公司管理稿、超级OPC稿、比赛PPT、Agent四层说明、a16z报告及赛事案例书。
- 保留已确定的演讲题目，先梳理大纲，再写讲稿，最后制作演示稿。
- 隐藏主线为：**理解能力变化 → 学会委派任务 → 看清企业流程 → 组织OPC交付 → 制定试点工作**。
- a16z报告放在开头，用于说明当下AI使用变化，再回到历史、能力、企业管理和实践；报告统计不能被外推为全球采用率或商业成功证明。
- AI历史需要讲清阶段转折与关键事件，不只罗列年份；例如突出达特茅斯会议，补齐20世纪60—90年代发展。

## 视觉决策的演进

最初是182×257毫米竖版年鉴。用户看过10张样稿后改为16:9横版并认可该方向，因此最终保留年鉴的蓝白橙、图文、人物横幅和页眉编号系统，重新适配演讲字号及横向布局。

用户接受120—150页，最终完成140页。这是内容组织的结果，不能变成新任务的固定页数。未来新项目无需再询问是否把此案例改回竖版。

## 该项目的特殊取舍

- 比赛介绍先讲整体定位、规模、流程和成果阶段，再讲用户指定的09、12、18三个项目。
- 三个案例各四页：导读、人物/团队、工作过程、成果与启示。缺少真实人像的项目使用明确标注的真实界面。
- 从参考PPT指定页段吸收内容，但保持整套成品统一风格；结尾沿用讲者原有致谢和联系资料。
- 所有固定授课分钟标签和休息倒计时从观众页面移除，现场节奏交由讲者判断。
- 用户后来要求删除含《Copilot2Agent》的整行来源小字：第61—112页和139—140页共54行被删除，其他正文、图片、讲稿和来源保持不变。该要求不能被泛化为任何新演讲都不显示外部出处。

## 可复用的完成方式

完整稿经过逐页渲染、翻页与跳转、总览、讲稿、演讲者窗口同步、图片放大、离线HTML及PDF检查；二维码从成品实际识别，交付包重新打开核对。

数字“140页”“54行”及过去的检查次数都是本例结果。新任务必须按自己的最终文件重新核验，不能沿用旧数字作为完成证明。
