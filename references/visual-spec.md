# Neo_PPT_skill 视觉规范

以下为已认可案例年鉴风格的可复用起点。继续修改已有稿时，以该稿实际参数为准；新项目允许按当前要求调整。

## 画布和色彩

| 项目 | 默认起点 |
|---|---|
| 比例 | 16:9横版 |
| 排版坐标 | 320×180毫米；与1920×1080预览同一比例 |
| 左右安全边距 | 各20毫米，约画布宽度6.25% |
| 主蓝 | `#0752CB` |
| 深蓝 | `#003B99` |
| 点缀橙 | `#F77532` |
| 纸白/正文黑 | `#FFFFFF` / `#111111` |
| 次要字/细线/浅色块 | `#566378` / `#CBD5E5` / `#EEF4FF` |
| 字体 | HarmonyOS Sans SC；使用实际可用且许可允许的字体文件 |

蓝色负责章节、标题和信息层级，橙色用于重点、编号及少量强调。正文以白底黑字为主。蓝底页面用白字，保持足够对比度。年鉴感来自稳定的边距、细线和编号，不依赖大量装饰。

## 字号与留白

在320×180毫米的排版坐标中，可从下列尺度起步，并以实际1920×1080画面检查：

| 元素 | 字号和行距参考 |
|---|---|
| 封面标题 | 约45—48磅，1.25倍行高 |
| 大章节标题 | 约42—43磅，1.3倍行高 |
| 普通页主标题 | 约30—34磅，1.28—1.3倍行高 |
| 小标题 | 约18—22磅，25—29磅行距 |
| 普通正文 | 约18磅，27磅行距 |
| 图文页/卡片正文 | 约14—17磅，20—26磅行距 |
| 次要图注 | 约9磅，13磅行距 |
| 三位页码 | 约13磅，加粗 |

表内尺寸是横版参考，不是把所有文字压到同一字号。正文过密时先减字、拆页或调整布局，避免靠缩字解决。图注不能承担本应在正文讲清的结论。

段首不缩进，段间留白，行距约为字号的1.4—1.5倍。正文保证一条清楚的阅读顺序；配图、并列卡片和对比内容可以分栏，不能把多个独立段落排成报纸式密集多栏。

## 页眉、页脚与安全区域

- 页眉由细线、演讲/书名和品牌标识构成；页脚为章节名与右侧001、002式三位页码。
- 页眉在画面顶端约8毫米处，正文起始通常距顶部27毫米以上；页脚在底部约7毫米处。
- 出处、结论和页脚各有空间，不相互覆盖。来源行被删除后不必为了填空整体放大正文。
- 大标题、人物资料、表格边缘、长链接和图注都必须留在安全区域。最后一行尤其要检查。

## 常用页面

| 页面 | 内容与布局 |
|---|---|
| 封面 | 左侧标题、主题说明和讲者信息；右侧主题相关立体像素场景插画 |
| 章节过渡 | 独立蓝底，清楚的章节标题、简短问题或承接句；可用橙色大编号 |
| 案例编辑导读 | 蓝底先讲“为什么看这个案例、要观察什么”，避免提前堆完整结果 |
| 人物/团队首页 | 顶部蓝带约占高度三分之一，左资料、右真实照片；下方白底交代业务责任与方法 |
| 白底图文正文 | 标题下方用少量要点说明事实，相关图片紧邻文字，图下注明身份与出处 |
| 工作过程 | 展示输入、步骤、交接、人和AI分工、输出与验收；连线和箭头保持简洁 |
| 工具卡片 | 重复排列相同结构：工具名/真实标识、用途、具体任务、适用边界 |
| 数据/榜单 | 大图表、大数字和清楚单位；长榜单分段放大，保留完整原图入口 |
| 互动/练习 | 清楚的问题、步骤、交付物；不在屏幕规定固定分钟数 |
| 结尾/联系 | 收束主线与行动，使用本次讲者提供的真实联系方式和二维码 |

人物页下半部分可先安排两组核心资料；增加资料前检查纵向空间，不让第三组挤入来源或页脚。对低清原型照片避免过度放大，保留原图标签并简述其版本。

## 真实图像的展示

- 以清楚表达为目标选图，而非纯装饰。人物、历史事件、产品界面和原始报告图优先使用真实材料。
- 等比缩放，默认完整展示；必须裁切时明确裁切目的，保留含义、关键标签和原图入口。
- 原始海报若包含概念图与实拍，只把确认为实拍的区域称作实拍。局部截图仍要指明来源。
- 图片文字在当前页无法读清时拆页或放大重点区域；点击放大是补充，不应成为理解整页的唯一途径。

早期提出的182×257毫米竖版、10磅正文/15磅行距/12磅小标题，仅适用于另做阅读型年鉴。默认演讲版采用本文件的16:9尺度，不把竖版页面简单拉宽。
